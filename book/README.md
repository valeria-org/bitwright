# The bitwright book

The guide to bitwright, written with [mdBook](https://rust-lang.github.io/mdBook/). Read it
online at <https://valeria-org.github.io/bitwright/>, or here on GitHub starting from the
[table of contents](src/SUMMARY.md). Every Rust example in it is compiled and run as a test
(`cargo test -p bitwright --doc`).

To read it locally, run `mdbook serve book` from the repository root and open
<http://localhost:3000>.
