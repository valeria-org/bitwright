# Bit-vector identities for `versus-smt --facts`: each line is `name [sort]: LHS ==> RHS`, where
# RHS is a simpler term equal to LHS for every value of the variables, at every width the set
# is run at (8 and 64 bits). The terms are SMT-LIB 2.6 QF_BV over x, y, z (the base width) and p
# (a Boolean). Written from textbook bit-vector algebra, not from any tool's rules; identities
# that trade sums of bitwise functions for other expressions (mixed boolean-arithmetic) are left
# out, since the MBA comparison is on CoBRA's datasets.
#
# `[sort]` is the root's sort when it is not the base width: `bool`, `2w`, or a width written
# like the indices below (`h`, `w-3`, `1`). The other sets in this directory (number theory,
# orders, slices, bit tricks, canonical forms) use the same format.
# `{E}` is an integer (an index); `[E]` a constant of the base width, `[E@2w]`, `[E@h]`, `[E@1]`
# one of another width. E is evaluated modulo 2^width: numbers, `w` and `h` (the base and half
# widths), `ones`, `smin`, `smax` (of the constant's width), `inv(K)` (the inverse of an odd K),
# `+ - * << >> & | ^ ~` and parentheses.
